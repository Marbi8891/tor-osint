# Código de conducta

Este proyecto quiere ser un espacio útil y respetuoso para cualquier persona interesada en
OSINT y ciberseguridad, sin importar su experiencia, origen o identidad.

## Lo que esperamos

- Trato respetuoso y constructivo en issues, pull requests y revisiones.
- Críticas centradas en el código y las ideas, nunca en las personas.
- Paciencia con quien está aprendiendo: este es también un proyecto de aprendizaje.
- Responsabilidad: no compartir direcciones de servicios ilegales, datos personales,
  credenciales filtradas ni material obtenido de forma ilícita.

## Lo que no se acepta

- Acoso, insultos, lenguaje discriminatorio o ataques personales.
- Publicar información privada de otras personas (doxxing).
- Usar el proyecto o sus canales para promover actividades ilegales o dañinas.
- Proponer cambios cuyo objetivo sea ampliar el alcance de la herramienta hacia la
  explotación, la evasión de controles o el descubrimiento masivo de servicios
  (ver [CONTRIBUTING.md](CONTRIBUTING.md)).

## Cómo reportar

Si ves un comportamiento que incumple este código, contacta con el mantenedor de forma privada
mediante el [reporte privado de GitHub](https://github.com/Marbi8891/tor-osint/security/advisories/new)
indicando que se trata de una cuestión de conducta. Los reportes se tratarán con
confidencialidad.

El mantenedor puede editar o eliminar contenido y restringir la participación de quien
incumpla estas normas.

Inspirado en el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
